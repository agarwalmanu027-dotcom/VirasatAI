4. MAIN PROJECT IDEA
==================================================

VirasatAI is an AI-based mobile application designed to help users explore Indian heritage places.

A user can capture or upload an image of a supported Indian monument.

The application will process the image using an Artificial Intelligence model and identify the monument.

After identification, the application will provide useful information about the monument.

The project is not only a monument classifier. It combines several heritage-related features inside one mobile application.

==================================================
5. MAIN FEATURES OF VIRASATAI
==================================================

The main planned features are:

1. Monument Identification

The user can:
- capture a monument using the mobile camera
OR
- upload an existing image

The AI model will analyze the image and identify the monument.

The first version will support selected Indian monuments rather than claiming to recognize every monument in India.

--------------------------------------------------

2. Monument Information

After successful identification, the application will show information such as:

- Monument name
- History
- Architecture
- Important facts
- Related images

Information should be written in simple language.

--------------------------------------------------

3. Nearby Heritage Places

The application will show other heritage or historical places located near the identified monument.

Example:

If the user identifies the Taj Mahal, the application may also suggest nearby historical places in Agra.

This feature is intended to help users explore more heritage locations rather than only one monument.

--------------------------------------------------

4. Multilingual Information

Heritage information should be available in multiple languages.

The purpose is to make heritage information easier for different types of users.

The exact languages can be finalized later depending on implementation.

--------------------------------------------------

5. Audio Storytelling

Users should have an option to listen to the history/story of a monument.

The audio feature does not need to be synchronized with every image.

The application can simply have:

Image Gallery

and a separate:

“Play Story” / “Listen” option.

Scripts may be created in:
- English
- Hindi
- other supported languages later

Typical monument audio/story length discussed:
approximately 1–2 minutes.

--------------------------------------------------

6. Litter / Waste Detection

VirasatAI will also include a cleanliness-related AI feature.

The user can capture or upload an image of an area around a heritage location.

The application can analyze the image and detect visible litter or waste.

The exact AI technique may be:
- image classification
OR
- object detection

The final approach should be selected according to:
- available dataset
- training results
- project complexity

Do not make this feature unnecessarily complicated.

20. TRANSFER LEARNING
==================================================

Transfer Learning may be used.

Instead of training a complete deep-learning model from zero, a pre-trained image-classification model can be adapted to the monument dataset.

Advantages for this project:

- less training time
- smaller dataset requirement
- suitable for student projects
- can provide good performance
- easier to implement than building a deep CNN completely from scratch

Do not finalize a specific pretrained model unless testing is performed or the user decides one.

33. MAIN ALGORITHM STEPS
==================================================

A simple monument-identification algorithm previously prepared is:

1. Take or upload an image from the user.

2. Check and prepare the input image.

3. Resize and preprocess the image.

4. Send the processed image to the trained CNN model.

5. Extract important visual features from the image.

6. Predict the monument class.

7. Identify the monument name.

8. Search for related information in the database.

9. Display monument information and images.

10. Display nearby heritage places and other available features.
